A constitution amendment's version bump MUST follow semantic versioning: MAJOR for a principle removed, a NON-NEGOTIABLE relaxed, or a materially changed governance model; MINOR for a new principle added or an existing one materially expanded; PATCH for wording, clarifications, typo fixes, or other non-semantic refinements.
