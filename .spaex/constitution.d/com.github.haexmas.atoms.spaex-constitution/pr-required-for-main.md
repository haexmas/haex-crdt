All work on this repo **MUST** land on `main` through a pull request; `main` is branch-protected and direct commits or pushes to it are rejected by the remote. Work happens on a topic branch, and a docs-only change is not exempt. This does not prescribe a universal branch-name format: work performed through project tooling follows that tooling's own configured convention.
