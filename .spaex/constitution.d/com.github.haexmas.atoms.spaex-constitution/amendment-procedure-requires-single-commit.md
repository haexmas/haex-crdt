Amending this constitution MUST update this document and bump its version per the semantic-versioning rules in the same commit. An ADR under `docs/adr/` is additionally required exactly when the change materially affects a Core Principle's substance (see the `adrs-for-principle-affecting-decisions` fragment); a pure wording, typo, or non-semantic clarification fix does not need one.
