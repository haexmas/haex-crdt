Feature work MUST be sequenced by phase. Later-phase features MAY be specified in advance, but MUST NOT be implemented before their own phase's prerequisites are actually in daily use. The current phase sequence is tracked in the project's own planning docs, not pinned to a specific document name in this constitution, so the sequencing rule stays valid as those docs are superseded or reorganized.
